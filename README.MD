# FashionStore — Plataforma E-commerce Omnicanal

Sistema integral de comercio electrónico omnicanal para cadena de ropa femenina con múltiples sucursales físicas y tienda online.

## Estado del Proyecto

- **Fase 1 (Backend & Autenticación)**: Implementada y verificada ✅
  - FastAPI + PostgreSQL + SQLAlchemy 2.x + Alembic + Psycopg 3
  - Modular Monolith + Clean Architecture
  - Autenticación segura (Argon2 + JWT)
  - Control de acceso basado en roles (RBAC)
  - Cobertura de pruebas unitarias e integración con Pytest

Para más detalles e instrucciones de ejecución técnica del backend, consulta el archivo [backend/README.md](backend/README.md).
